Visão Geral

Este serviço de impressão foi projetado como uma alternativa moderna ao CUPS, oferecendo uma API REST para gerenciamento de filas, impressoras e trabalhos de impressão, com integração nativa a aplicações web e ambientes corporativos.

Objetivos principais:
  • Gerenciamento centralizado de impressão
  • API REST documentada
  • Monitoramento de status em tempo real
  • Integração com sistemas externos

Arquitetura

A aplicação é composta por um backend FastAPI responsável pela API, orquestração das filas de impressão e comunicação com os drivers do sistema.

Segurança

O serviço suporta autenticação baseada em token e pode ser integrado a mecanismos de autenticação corporativa.

  • Autenticação via API Key / JWT
  • Controle de acesso por função
  • Logs de auditoria

FAQ

Este serviço substitui o CUPS?

Ele pode operar como camada de abstração ou substituição parcial, dependendo da configuração e do ambiente.

Funciona em contêiner?

Sim. A aplicação foi projetada para rodar em Docker e ambientes orquestrados.
